# Gestión de Empleados – Aplicación de Escritorio

Aplicación de escritorio desarrollada en pareja que permite capturar, validar y almacenar
información de empleados en un archivo de texto utilizando un cuadro de diálogo,
similar al proceso de guardado de archivos en Microsoft Word o PowerPoint.

El sistema está orientado a reforzar el manejo de formularios, validaciones,
archivos de texto y experiencia de usuario.

---

## Datos del empleado
La aplicación permite capturar los siguientes datos:
- ID
- Nombre
- Apellidos
- Dirección
- Teléfono
- Email
- Cargo
- Salario
- Fecha de ingreso
- Género

---

## Funcionalidades
- Validación de que todos los campos estén completos
- Mensajes de alerta al generar el archivo de texto
- Mensaje de confirmación al intentar salir de la aplicación
- Guardado del archivo con un nombre definido por el usuario mediante cuadro de diálogo
- Apertura automática del archivo guardado

---

## Requisitos cumplidos
- Los datos se almacenan en un archivo de texto en formato de tabla
- Interfaz con criterios básicos de usabilidad y accesibilidad
- Proyecto subido a un repositorio de GitHub
- Inclusión de este archivo README como documentación del proyecto

---

## Tecnologías utilizadas
- Lenguaje: C#
- Framework: .NET
- Interfaz gráfica: Windows Forms
- Entorno de desarrollo: Visual Studio
- Manejo de archivos: Archivo de texto (.txt)
